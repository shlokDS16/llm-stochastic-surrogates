# RQ1 descriptive tables (runs/rq1-tables)

Generated by `analysis/rq1/rq1_tables.py`, config `runs/rq1-tables/config.json`. Evidence level E4 (computed here), on abstract-level codes.

## What these numbers are
RQ1 is **abstract-level coding by Claude Sonnet** (frozen brief `research/protocol/rq1-abstract-coding-brief.md`, blind to all screening labels), not full-text extraction. A paradigm, model or language is counted only when the title or abstract names it; an empty field means 'not named in the abstract', not 'absent from the study'.

## Views and denominators (protocol v0.9 item 2; neither view is the headline)
- **View A**: liberal frame, N = 2022 (abstract-decisions-v08, `liberal == eligible`).
- **View B**: coder-flagged subset of A, `meets_criteria_on_abstract == yes`, N = 992. The flag distribution in A is yes 992, unclear 759, no 271. (Amendment v0.9 reports 996 yes over all 2,032 coded records, which include the 10 pilot-only records outside the frame.)
- **Sensitivity S**: strict frame, N = 1470 (`strict == eligible`; all strict records are in A). Reported as a third column, all records of the strict frame regardless of the flag.
- Percentages use the view's N as the denominator, including for n_models_stated rows ("% of N stated"). Paradigm families, model families and languages are counted per record (at least one item), so those columns do not sum to N. T-RQ1d and Fig 2 use the first paradigm family listed by the coder (the sample-design rule, v0.9.1), so rows sum to the view total.

## Error estimates of the coder flag (quoted, not recomputed)
Source: `runs/fulltext-pilot/rq1-flag-crosstab.md` (sha256 `4f02e92bea61a651...`), amendment v0.9 item 3. Wilson 95 percent intervals as written in the source:

> Records used: 53 (reference YES 32, NO 21).
- False exclusions (reference YES, flag no): 1/32 = 0.03 [0.01, 0.16]
- Reference YES flagged unclear: 11/32 = 0.34 [0.20, 0.52]
- False inclusions (reference NO, flag yes): 0/21 = 0.00 [0.00, 0.15]
- Reference NO flagged unclear: 8/21 = 0.38 [0.21, 0.59]

Limits stated in protocol v0.9: 53 usable records, which also chose the screening rule (partly post-selection); the flag is an additional measurement, not a gold standard, and was not tuned after the check. The false-exclusion rate of view B relative to view A is therefore uncertain (1/32 missed, interval 0.01 to 0.16), and 'unclear' (about a third of reference-YES and reference-NO alike) is not resolved by the abstract.

## Other caveats
- Years come from `records.jsonl` (`year`); 2026 is a partial year (search run 2026-10-16).
- Model-family and language assignments were made by the coder from the abstract; 'other' covers all families not on the fixed list (for example DeepSeek, Grok).
- T-RQ1e merges only exact matches after normalisation; near-synonymous names stay separate, so counts understate paradigm frequency.
